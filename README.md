CVSS v4.0 Vector Generator

A simple console‑based tool for generating a CVSS v4.0 vector string from user input.

This project is a beginner implementation of a CVSS (Common Vulnerability Scoring System) v4.0 vector generator.
It was created for a class assignment to demonstrate:

Basic C# console input/output

User input validation

Exception handling

Constructing a valid CVSS vector string from metric codes

The current version focuses on one metric (Attack Vector – AV), but the structure is intentionally clean and expandable.

Future Development: Full CVSS v4.0 Generator
This assignment version is intentionally simple, but the long‑term goal is to evolve it into a fully functional, CVSS v4.0 generator.
